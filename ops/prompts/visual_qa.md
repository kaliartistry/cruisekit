# CruiseKit Visual QA

Review changed public pages across desktop and mobile. Confirm text does not overlap, CTAs are visible, app screenshots and photos render, images have appropriate alt text, interactive tools fit their containers, and no competitor screenshots/logos are used without permission.

For image sourcing, prefer existing local CruiseKit assets. If an external image is needed, use a clearly safe source with a license or attribution trail and record the source in the PR/report. Do not hotlink random images from unrelated websites. Record public-safe QA notes in the PR or daily report.
