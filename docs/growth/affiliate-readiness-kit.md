# Affiliate Readiness Kit

Status: planning only. No affiliate additions were made in this cycle.

## Requirements Before Adding Or Scaling Affiliate Links

- Confirm each partner is relevant to the page intent.
- Confirm the page already satisfies the user without requiring a click.
- Use clear affiliate disclosure near the link and in site-wide disclosure.
- Track outbound clicks with existing `outbound_affiliate_click` and `port_page_affiliate_click` helpers.
- Do not place affiliate links in Reddit or Facebook communities unless explicitly allowed and separately approved.
- Do not use misleading savings, scarcity, or guaranteed-availability claims.

## Priority Page Types

1. Port pages with excursion intent.
2. Hidden-cost article sections where insurance, parking, hotels, or excursions are already discussed.
3. Cruise cost calculator results when the user explicitly selected a relevant add-on.
4. Line-specific cost pages only where the affiliate product solves that line-item need.

## Approval Gate

Before adding any new affiliate placement, create a short proposal with:

- URL
- Partner
- Link destination
- User intent
- Disclosure copy
- Tracking event
- Expected risk

Do not implement until approved.
